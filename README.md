# Credit Scoring Model

## Project Overview
This project uses Machine Learning to predict credit risk based on financial data.

## Objective
The objective is to explore how machine learning can help assess the creditworthiness of individuals.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning
The project uses a classification model to predict credit risk.

## Project Files
- credit_scoring.py: Python source code
- cs-training.csv: Training dataset
- cs-test.csv: Testing dataset
- sampleEntry.csv: Sample submission format
- Data Dictionary.xls: Dataset column descriptions

## Conclusion
This project demonstrates the application of machine learning techniques
to credit risk assessment.
